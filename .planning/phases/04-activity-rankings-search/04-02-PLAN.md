  <action>
Add three new functions to the existing birdeye.ts:

**1. getTokenOverview(address: string, chain: BirdeyeChain)**
- Endpoint: GET /defi/token_overview
- Params: { address }
- Headers: { 'x-chain': chain }
- Response type interface (add near top of file):
  ```typescript
  interface BirdeyeTokenOverviewResponse {
    success: boolean;
    data: {
      address: string;
      symbol: string;
      name: string;
      price: number;
      priceChange24h: number;
      volume24h: number;
      liquidity: number;
      mc: number;
      trade24h?: number;
      trade24hChangePercent?: number;
      buy24h?: number;
      sell24h?: number;
      uniqueWallet24h?: number;
      uniqueWallet24hChangePercent?: number;
    };
  }
  ```
- Return: data object or null on error
- Log errors but don't throw (return null for graceful degradation)

**2. searchTokens(keyword: string, chain: BirdeyeChain)**
- Endpoint: GET /defi/v3/search
- Params: { keyword }
- Headers: { 'x-chain': chain }
- Response type interface:
  ```typescript
  interface BirdeyeSearchResponse {
    success: boolean;
    data: {
      items: Array<{
        type: 'token' | 'pair';
        result: {
          address: string;
          symbol: string;
          name: string;
          logoURI?: string;
          decimals?: number;
          liquidity?: number;
          volume24h?: number;
          price?: number;
        };
      }>;
    };
  }
  ```
- Filter to only return items where type === 'token'
- Return array of token results (map to simpler structure)

**3. searchAllChains(keyword: string)**
- Iterates over BIRDEYE_CHAINS (solana first, then ethereum, base, arbitrum, bsc, polygon, optimism, avalanche, zksync, sui, aptos)
- Calls searchTokens for each chain with 100ms delay between calls
- Returns Record<BirdeyeChain, SearchResult[]> grouped by chain
- Limit to top 5 results per chain
- Handle errors per-chain gracefully (skip chain, continue)

Export all three functions and the new response types.
