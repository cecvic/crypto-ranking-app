  <action>
Create `src/lib/scoring/` directory with three files:

**normalizers.ts:**
- PercentileLookup interface: { volume24h: number[], trade24h: number[], uniqueWallet24h: number[], liquidity: number[] }
- buildPercentileLookup(tokens: TokenWithMetrics[]): PercentileLookup - sorts each metric array
- percentileRank(value: number, sortedArray: number[]): number - returns 0-100 using simple-statistics quantileRank
- normalizeToRange(value: number, minIn: number, maxIn: number, minOut: number, maxOut: number): number - linear normalization clamped to output range

**activity-score.ts:**
- ActivityMetrics interface: { volume24h, trade24h, uniqueWallet24h, buy24h, sell24h, priceChange24h }
- ActivityScore interface: { total, volumeScore, tradeScore, walletScore, momentumScore } (all 0-100)
- calculateActivityScore(metrics: ActivityMetrics, percentiles: PercentileLookup): ActivityScore
  - volumeScore = percentileRank(volume24h, percentiles.volume24h)
  - tradeScore = percentileRank(trade24h, percentiles.trade24h)
  - walletScore = percentileRank(uniqueWallet24h, percentiles.uniqueWallet24h)
  - momentumScore = combine priceChange24h with buy/sell ratio, normalize to 0-100
  - total = weighted sum: volume 0.30, trade 0.25, wallet 0.25, momentum 0.20
- Handle null/undefined metrics gracefully (default to 0, which gives low percentile)

**opportunity-score.ts:**
- OpportunityScore interface: { total, activityScore, liquidityScore, riskAdjusted }
- calculateOpportunityScore(activityScore: ActivityScore, liquidity: number, volume24h: number, percentiles: PercentileLookup): OpportunityScore
  - liquidityScore = percentileRank(liquidity, percentiles.liquidity)
  - riskMultiplier: 0.5 for liquidity < 10k, 0.75 for < 50k, 0.9 for < 100k, 1.0 otherwise
  - healthyRatio bonus: +15 if volume/liquidity ratio between 0.5 and 2.0
  - total = (activity * 0.60 + liquidity * 0.25 + bonus) * riskMultiplier, capped at 100

Use simple-statistics for quantileRank (already in package.json). Export all interfaces and functions.
  </action>

  </verify>
